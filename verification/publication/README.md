# 发布整理后的复测（2026-10-13）

目录名称为 `Webots_Robotics_TDP`。复测使用 Ubuntu 20.04.6、Webots R2023b 和 Conda Python 3.10.22。

- 33 项逻辑测试通过，耗时 2.840 秒。
- `geometry-webots.log`：实际世界加载、八个控制器、球门净宽/高、整球计分、重置、开球分离和重启距离处罚检查通过。
- `vision-webots.log` 与 `vision-vision-result.json`：实际底部相机和随包检测器检测成功，单个静止夹具的平面误差约 0.01003 m。
- 两份 `*-manifest.json` 保存实际运行时的配置与源码散列；本机解释器和临时目录路径已脱敏。
- 未复测长时间四对四、步态性能或真实硬件。单场景视觉误差不代表总体准确率。

模型权重与发布整理前的备份 SHA-256 一致。逻辑实现与几何参数在发布整理中保留；可选 Gazebo 模型路径调整未经过 ROS/Gazebo 运行验证。
